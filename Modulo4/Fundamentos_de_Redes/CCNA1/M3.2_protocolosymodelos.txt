Modelos de referencia son las capas OSI y las tCP

Aplicación > la capa contine protocolos utilizados para comunicaciones proceso a proceso, de comunicaciones

Presentación > la capa de presentación proporciona una representación común de los datos transferido entre los servicios de capa de aplicación

Sesión > Proporciona servicios a la capa de presentación para organizar el dialogo y administrar el intercambio de datos

Transporte > define servicios para segmentar, transferir y volver a montar los datos para las comunicaciones individuales entre el final

Red > proporciona servicios para intercambiar las piezas individuales a través de la red entre los endpoints identificados

enlace > los protocolos de la cpa de enlace de datos describen métodos para intercambiar datos, tramas entre dispositivos a través de un medio común

física > describen los componentes mecánicos, eléctricos, funcionales y de procedimiento para activar, mantener y desactivar conexiones físicas para una transmisión de bits hacia y desde una red
